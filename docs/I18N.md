# Internationalization (i18n)

BCL Diocese ERP supports enterprise multilingual deployments with diocese-scoped language configuration.

## Locale codes

| Code | Language | Native name |
|------|----------|-------------|
| `en` | English | English |
| `gar` | Garo | A∙chik |
| `ta` | Tamil | தமிழ் |

Legacy alias: `garo` → `gar` (liturgy and push targeting).

## Architecture

- **UI strings**: `@bcl/i18n` JSON bundles (`common`, `erp`, `cms`, `certificates`, `emails`, `reports`, `mobile`) merged with optional diocese overrides in `UiTranslationNamespace`.
- **CMS & domain content**: `*Translation` tables (pages, posts, events, menus, parishes, notifications, emails).
- **User preference**: `User.preferencesJson.locale`
- **Diocese config**: `DioceseLanguage` (enabled, default, sort order)
- **Cache**: in-memory `I18nCacheService` (Redis-ready keys)

## Resolution chain

1. User `preferences.locale` (if enabled for diocese)
2. Diocese default language
3. Browser / device `Accept-Language`
4. English fallback

## API endpoints

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/i18n/languages` | Enabled languages for org |
| PUT | `/i18n/diocese/languages` | Configure diocese languages |
| GET | `/i18n/messages/:locale/:namespace` | Public namespaces (`common`, `cms`, `mobile`) |
| GET | `/i18n/messages/:locale/:namespace/authenticated` | Protected namespaces (`erp`, etc.) |
| POST | `/i18n/import` | Upload JSON override |
| GET | `/i18n/export/:locale/:namespace` | Download merged JSON |
| GET | `/i18n/search?q=` | Search translated CMS content |
| GET | `/cms/public/:slug?lang=` | Localized public parish site |

## RBAC

- `i18n.read` — view languages and translations
- `i18n.write` — manage diocese language settings, import/export
- `i18n.translate` — edit translation values (TRANSLATOR role)

## Adding a new language (no code changes)

1. Super Admin registers language in `Language` catalog (or upload via future admin UI).
2. Add JSON files under `packages/i18n/locales/{code}/`.
3. Diocese Admin enables the language at **Diocese → Languages**.
4. Optionally import diocese-specific overrides.

## Web & mobile

- **Web**: `next-intl` via `LocaleProvider`, cookie `bcl_locale`, language switcher in top bar.
- **Mobile**: `i18next` + `expo-localization`, instant switch in Profile → Settings.

## AI translation (scaffold)

`TranslationJob` + `TranslationSuggestion` models support future LLM-assisted translation with human review before publish.
